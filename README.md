# Coding Practice

A C# solution for practicing coding problems organized by topic.

## Structure

Each topic has its own project:

- **ArraysAndStrings** - Array and string manipulation problems
- **LinkedLists** - Linked list problems
- **StacksAndQueues** - Stack and queue problems
- **TreesAndGraphs** - Tree and graph problems
- **BitManipulation** - Bit manipulation problems
- **RecursionAndDynamicProgramming** - Recursion and dynamic programming problems
- **SortingAndSearching** - Sorting and searching algorithms
- **AdditionalProblems** - Miscellaneous problems

## Adding New Problems

To add a new problem to any project:

1. Open the `Program.cs` file in the relevant project
2. Add your problem solution in the `Main` method or create new methods
3. Build and run the project to test your solution

## Building and Running

To build the entire solution:
```bash
dotnet build
```

To run a specific project:
```bash
dotnet run --project ArraysAndStrings
```

Or open the solution in Visual Studio or your preferred IDE.
